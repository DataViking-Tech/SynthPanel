# althing

This npm name is reserved by the [Althing](https://althing.dev) project —
an open-source research harness for running synthetic focus groups and
panels with AI personas (CLI + MCP server), formerly known as *synthpanel*.

**Althing is a Python project.** Install the real package from PyPI:

```bash
pip install althing
```

- Site: <https://althing.dev>
- Source: <https://github.com/DataViking-Tech/Althing>
- Benchmark: <https://synthbench.org>

If a JavaScript SDK ships in the future, it will live under this name.
